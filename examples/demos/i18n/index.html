stress i18n

Buttons that overflow when the copy gets longer

Every text run is lengthened 1.4x, roughly what translating English into German does, and the layout is measured again. No translations needed.

Open the page under test · fixtures/i18n-stress/button-overflow/page.html

Run it

vlmkit stress i18n fixtures/i18n-stress/button-overflow/page.html --output-dir {out}

What to look at

A fixed-width button and heading overflow, and a paragraph doubles in height. Each finding carries the scroll width against the box.

The fix

Replace the fixed widths with min-width and let text wrap.
