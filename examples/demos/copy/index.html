Copy that drifted from the spec

The manifest (copy.txt, published here as manifest.txt) is the copy the page must show, verbatim. The page reworded the button, hid a pricing note in the page's own colour, and shipped a placeholder quote.

Open the page under test · examples/demos/copy/page.html · manifest.txt

Run it

vlmkit check copy examples/demos/copy/page.html --manifest examples/demos/copy/copy.txt

What to look at

The hidden note IS in the DOM, so a text search passes it. The gate reports it as copy-invisible with the reason class (camouflage) because a user cannot see it.

The fix

Restore "Start a free trial", give .note a real colour, and write the testimonial.
