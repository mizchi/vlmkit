scan a11y → check a11y tree

An app with no DOM to read

A canvas app paints its UI and exposes only an accessibility tree, so DOM contrast rules read every label as 1.00:1. scan a11y writes the tree plus the frame; check a11y tree judges it, with contrast taken from the frame's pixels.

Open the page under test · fixtures/a11y-tree/flutter-like.html

Run it

vlmkit scan a11y fixtures/a11y-tree/flutter-like.html --out {out}/a11y.json
vlmkit check a11y tree {out}/a11y.json

What to look at

Four kinds of finding from one frame: a text field with no name, content past the bottom that nothing scrolls to, a 2.32:1 hint, and a 20x20 target.

The fix

Label the field, make the log scrollable, darken the hint, grow the Info target to 24px.
