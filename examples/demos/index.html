vlmkitDemos

vlmkit, one defect at a time

Each demo is a page with something wrong in it and the command that finds it. The output on every page is what the command printed. The screenshots are from the same run, and the outlines mark only elements the tool itself named. Most pages are the repository's own test fixtures, so the same commands work from a clone.

npm install -D @mizchi/vlmkit
npx playwright install chromium
npx vlmkit check integrity http://localhost:3000/

Is the page broken?

Reference-free checks for the page you just wrote. No baseline, no design file, no API key.

  • check integrity A pricing page that breaks on smaller screens
  • check copy --manifest Copy that drifted from the spec
  • check responsive A card grid that needs 826px, switched on at 768px

Can it be operated?

Keyboards, focus order, and agents that click on a screenshot.

  • check interactions A Save button that does nothing on Enter
  • check a11y focus A toolbar whose Tab order runs backwards
  • check grounding --mark A checkout button an agent would miss

Can everyone read it?

Contrast measured on rendered pixels, including apps with no DOM at all.

  • check a11y contrast Pale text that fails WCAG contrast
  • scan a11y → check a11y tree An app with no DOM to read

Does it look designed?

Proximity, colour roles and a spacing scale. These report inconsistency, never taste.

  • check composition Headings that sit closer to the section above
  • check color Links you can only tell apart by colour
  • check tokens Spacing and radii off the design scale

What changed?

Two versions of a page, or one page under a longer language.

  • diff html A header that grew 48px and pushed everything down
  • stress i18n Buttons that overflow when the copy gets longer

Vision models and figures

Letting a VLM zoom into the original, and figures that are checked against what they claim.

  • @mizchi/vlmkit-ai/zoom.ts Letting a vision model zoom into the original
  • vlmkit-anim check An algorithm as a checked animation

Whole sites built by agents, each with the log of how it was judged: demo sites. A playable card game used as a drag-and-drop target: solitaire.
