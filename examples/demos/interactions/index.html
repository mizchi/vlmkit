A Save button that does nothing on Enter

Every control is focused and pressed from the keyboard, and the page is watched for a response: an ARIA change, a layout change, a navigation.

Open the page under test · fixtures/interact/dropdown-form/page.html

Run it

vlmkit check interactions fixtures/interact/dropdown-form/page.html

What to look at

The dropdown answers Enter with a layout change. The Save button answers with nothing, so it is reported as an inert control.

The fix

Make Save a real submit (or handle keydown), so the keyboard gets what the mouse gets.
