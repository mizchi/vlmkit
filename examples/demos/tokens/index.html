Spacing and radii off the design scale

Hard-coded values audited against a spacing, radius, z-index and shadow scale. Nothing on this page looks wrong at a glance, and that is the point.

Open the page under test · fixtures/design-tokens/off-scale/page.html

Run it

vlmkit check tokens fixtures/design-tokens/off-scale/page.html --output-dir {out}

What to look at

Twenty values off the scale, each with the nearest value on it: 14px and 18px paddings between 12, 16 and 20; radii of 5, 7 and 9px; eight distinct shadows where five tiers are allowed. The markdown report beside the run has one row per value.

The fix

Snap each value to the nearest token.

## Suggested next step

1. Replace each violating value with its nearest in-scale equivalent (the "Nearest in-scale" column).
2. If a value needs to be off-scale (intentional outlier), document why in a comment — the violation is a code smell, not a hard ban.
3. Consolidate `box-shadow` values into a small named tier set (e.g., `--shadow-sm`, `--shadow-md`, `--shadow-lg`) and reference the variables instead of inline values.
4. Re-run `vlmkit check tokens`. The violation count should drop.
