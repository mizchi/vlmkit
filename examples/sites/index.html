How the logs were kept

Every log was written by one small tool as the work happened, under one protocol:

  • a gate runs through it, so its exit code and its whole output are kept rather than a summary of them;
  • a screenshot is taken through it, one screen per image, and a look is recorded against the image it describes; each finished round keeps the pictures of one full-page walk per width, so you can open them and disagree;
  • a defect must name the look or the gate run that found it, and a fix must be checked by a later look or run before the log can be marked done.
