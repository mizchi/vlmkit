quarry run

Runs a plan against the source and target databases. The command is resumable: run it again with the same plan and it continues from the last checkpoint.

quarry run --plan plans/orders.toml --parallel 8 --checkpoint .quarry/orders.ckpt

Options

Every option can also be set in the plan file. A flag given on the command line wins over the file.

Run quarry plan first: it estimates the size of each range and warns about tables without a primary key.

Exit codes

0 when the run finished, 3 when it paused at a checkpoint, and 1 for any error that needs a person to look at it.
