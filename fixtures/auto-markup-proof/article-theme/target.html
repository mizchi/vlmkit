Composition diffs land in build page

July 27, 2026 - 4 min read

The new build page command pairs component boxes spatially, so a missing card is reported as missing instead of cascading into nonsense pairings.

vlmkit build page target.png current.html --crop crops/

Stacking gap deltas now come with a direction, so an agent can apply "reduce 72px" without guessing which margin grew.
